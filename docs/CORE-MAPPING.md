# Adding mappings for other cores

The selector can capture additional standard v3 core maps. Only main-menu
and N64 maps are currently bundled. The systems below are suggested next
configuration/test targets, not claims that extra profiles have been tested.

## Where custom mappings are most useful

| Core | Why check its layout | What to test |
| --- | --- | --- |
| Saturn | Six face buttons (A/B/C and X/Y/Z), plus L/R, need a deliberate arrangement on a four-face-button pad. | Every digital button, Start and D-pad. Leave enough physical controls for L/R after assigning C/Z. |
| Mega Drive / Genesis | Three-button A/B/C already differs from a four-button diamond. Six-button games add X/Y/Z and Mode. | Both three- and six-button games; enable the core's six-button setting when needed and check the extra buttons. |
| Neo Geo | A/B/C/D placement and simultaneous-button moves matter. Different fighting games use different combinations. | All four attacks, Start, Coin and any shortcut combinations in the actual games you play. |
| PlayStation / PSX | Face-button shapes, L1/R1/L2/R2 and dual-stick controls need checking. Controller emulation and analog mode are separate from button mapping. | Digital-pad games and compatible analog/DualShock games; both sticks, stick clicks and any analog-mode toggle you assign. |

This order is a project recommendation based on those input requirements.
Xbox and Stadia are the best starting points for general layouts here because
they have four face buttons, two shoulder buttons, two triggers and two sticks.
The N64 mod has a different set of controls; a remap cannot add a missing
second analog stick. Preserve its familiar N64 layout and treat other-core
layouts as deliberate compromises.

Try existing controls first for simpler systems. Create an override when
something is wrong or uncomfortable, rather than remapping every core by habit.

## Capture without losing the work

1. Pair the pad, apply its saved profile in the correct receiver USB mode,
   exit the script and reconnect the pad to reload mappings.
2. Open the target core and configure/test its buttons. Check the core's own
   controller-type/input options as well.
3. Return to the selector and choose **Capture current maps**, select that
   same physical controller and confirm **Save current maps**.
4. Confirm the new core map appears in that controller's saved profile folder.
   Use its actual filename generated by MiSTer; do not guess a core prefix.
5. Only then switch profiles. Verify that switching away and back restores
   the new core layout after reconnecting.

**Capture before applying another profile.** Applying replaces the active
standard map set for the receiver identity and removes core maps absent from
the selected profile. Uncaptured work is therefore removed from the active
folder, although the selector's switch backup retains the previous files.

Capture saves the whole active standard map set, not just the last core you
configured. Starting with the correct pad profile prevents another pad's
leftover maps being saved under the wrong controller.

## Settings the profile does not carry

- Receiver USB output mode and the pad's Bluetooth pairing mode.
- Core controller emulation settings, such as PSX DualShock selection or the
  Mega Drive six-button option. These are core settings, not these `.map` files.
- Keyboard maps, `*_advanced_input_*` maps and other USB device identities.
- Per-game layout variants selected independently of the controller profile.

Neo Geo's game-specific combinations are a good example of that last limit:
one saved controller/core map is not a universal layout for every fighter.
MiSTer's standard alternate mappings can duplicate a button or combine two
core inputs. Verify the generated files are standard 128-byte v3 maps before
submitting them; the selector deliberately excludes advanced-map files.

## Primary references

Checked on 11 October 2026. Core revisions and menu labels can change.

- [Saturn core input definitions](https://github.com/MiSTer-devel/Saturn_MiSTer/blob/main/Saturn.sv), the controller definition lists A/B/C, X/Y/Z, L/R and Start. This guide targets the digital pad.
- [Mega Drive core input definitions](https://github.com/MiSTer-devel/MegaDrive_MiSTer/blob/main/MegaDrive.sv), the input menu has a six-button setting and the button definition includes Mode and X/Y/Z.
- [MiSTer multi-button mapping documentation](https://mister-devel.github.io/MkDocs_MiSTer/advanced/multibutton/), examples explain alternate mappings and differences between Neo Geo fighting games.
- [PSX core pad options](https://github.com/MiSTer-devel/PSX_MiSTer#pad-options), supported emulated controllers and digital/analog switching.
